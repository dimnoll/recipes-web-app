About

Welcome to Recipo, rebuilt with Node.js, TypeScript, and Hono, using the modern, responsive Verti template by HTML5 UP.
This project aims to provide an easy way for users to explore and search through a variety of delicious recipes. Whether you're a culinary enthusiast or just looking for meal inspiration, this platform offers a seamless browsing experience.

Features

  • Node.js and TypeScript, managed with pnpm
  • Hono routes and an in-memory recipe repository
  • Integration of a modern HTML5 responsive template
  • Template inheritance using Nunjucks
  • Modular static assets (CSS, JS, fonts)
